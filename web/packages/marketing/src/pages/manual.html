What is chan?

Chan is a scriptable terminal emulator for local and remote development. Arrange windows with split panes, switch each pane between its A and B sides, and open tabs for terminals, files, and other applications. Use the mouse, keyboard, or cs commands to control your environment. The terminal chapter covers shell tools and tmux control mode; Devserver covers remote connections.

A directory can become a workspace with its own index, BM25 search, document links, and graph. The editor supports Markdown, Excalidraw, and slide decks. Shared sessions coordinate participants and leadership, while extensions add your own applications as tabs.
