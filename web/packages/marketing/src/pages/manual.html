What is chan?

chan is a supercharged terminal emulator. It is easiest to understand as layers, each one built on the previous:

  • A terminal emulator. Terminals open in tabs and split panes inside windows. The shell and its scrollback live in a server process, not in the window, so a window can close or reload and the shell keeps running.
  • Scriptable. Every chan terminal has the cs command, which drives the window it runs in: open a file, split a pane, start a named terminal, type into another tab and read its output, copy to your clipboard, transfer files. The same actions are on the keyboard through the command launcher and on the mouse through pane menus and drag and drop. Programs report their state back to the tab, and the Rich Prompt composes Markdown and images into a program's input.
  • A multiplexer, and tmux. chan's own multiplexer is windows, panes, tabs, and named sessions that outlive the window. It also speaks tmux control mode: a tmux -CC run in a chan terminal, locally or over ssh, turns that tmux server's windows and panes into chan windows and panes.
  • Local and remote, the same. Chan Desktop runs the server on your machine. Chan Devserver runs the same server on another machine, and your desktop connects to it over any TCP tunnel you already have: an ssh -L port forward, a VM, a container. Disconnecting leaves everything running there.
  • Always on, through a gateway. A devserver can also dial out to a chan gateway, which publishes it behind sign-in to you and to the people you share it with, from any browser or desktop. The gateway is software you host yourself; chan is not an online service.

Around the terminal, chan turns any directory into a workspace: it indexes the content for search, gives Markdown files autocompletion for linking to each other, builds a graph of the project, and adds built-in apps (editor, file browser, graph, dashboard, and more) as tabs beside your terminals, so you and your coding agents work on the same project side by side. Shared sessions coordinate participants and leadership, while extensions add your own applications as tabs. chan is free and open source.

This manual describes chan from the outside. The design documents in the repository describe the same layers from the inside, component by component.
