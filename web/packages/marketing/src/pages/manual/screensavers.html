Idle screen lock

Open Settings → This workspace to configure screen lock. Idle locking is off by default. When enabled, the default timeout is five minutes; choose the timeout, a Default or Matrix theme, and an optional PIN.

The lock covers the workspace window while terminals keep running. With a PIN set, enter it to unlock. Without a PIN, dismiss the cover to return to the workspace. This is a workspace screen lock; use your operating system's lock to protect the rest of the computer.

Animations in an empty workspace

When a workspace has a single pane and no tabs on either side, chan can display an animation in the empty pane. These animations accompany an empty workspace; the idle screen lock is configured separately.
