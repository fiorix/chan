What you can do

  • Lock a workspace window after a stretch without input, or at once.
  • Ask for a PIN to unlock it, or let a key or click unlock it.
  • Choose a Default or a Matrix lock screen.
  • Watch an animation in an empty workspace, and step through the animations from the keyboard.

Idle screen lock

  1. Turn it on

    In Settings → This workspace → Screen lock, switch it On. It is off by default.

  2. Set the timeout

    Inactivity timeout (seconds) is 300 by default, from 10 to 3600.

  3. Set a PIN, if you want one

    Set PIN asks for it twice; Change PIN replaces it, and Clear PIN removes it.

  4. Choose a theme and try it

    Theme is Default or Matrix. Test locks the window at once.

The lock covers this window only. Terminals keep running behind it, and other windows and clients with the workspace's token still reach its sessions. Use your operating system's lock to protect the computer.

Animations in an empty workspace

A workspace window with one pane and no tabs on either side shows the chan mark, then an animation. Click the pane to give it the keyboard:

KeyDoes
Right LeftNext or previous animation.
Up DownFaster or slower.
?A random animation.

Workspace animations and credits plays each animation, switches themes, and links to the original authors and references, including the Matrix screen lock's.

Details and limits
  • The screen lock is a setting of each workspace; a standalone terminal has none.
  • With a PIN set, Esc and a click on the lock screen do not unlock it.
  • Wrong PINs are not rate-limited. The lock keeps a passer-by out of the window; it does not secure the workspace.
  • The animations are separate from the screen lock and need no setting.
  • Which animations play depends on the graphics the window can use.
  • A window with more than one pane, or a pane with tabs on its hidden side, shows only the chan mark.
