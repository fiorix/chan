What you can do

  • Watch the chan process that serves the window: CPU, memory, network, disk I/O and file transfers over the last ten minutes.
  • Read a workspace's size, file kinds, code report and contacts.
  • Follow indexing directory by directory.
  • Choose which slides show, and stop the rotation.
  • Turn on semantic search, and choose what the index leaves out.

Watch the server process

Metrics shows the chan process that serves the window: Chan Desktop for its own windows, the devserver for a devserver's windows, and chan serve for the workspace it serves. The readings are that process's own; the shells, agents and other programs it started are not counted.

CardReads
HeaderThe host, the process id, the chan version and build, and the uptime.
CPUPercent, where 100% is one logical core.
MemoryResident memory.
Networkchan's own receive rate, with the send rate beside it. Not the machine's traffic.
I/O read, I/O writeThe rates, with the totals.
File transfersRunning transfers, the queue and the workers.
Channels & tunnelsGateway tunnels, reverse listeners, and the HTTP/2, yamux and reverse TCP channels in use.
StorageThe size and file count of the chan home: ~/.chan, or the directory CHAN_HOME names.

With privacy mode on, the host name, the chan home path and storage scan errors each hide behind a reveal button. chan metrics prints the same readings in a shell; see Run a devserver.

Follow the index

Each workspace has its own index, kept under the chan home, not in the workspace. It makes content searchable, gives the graph its links, tags and mentions, and follows the files as they change.

  • The Search slide draws the directories as a graph: green when indexed, pulsing orange while indexing, grey while pending. Click a directory for its Details.
  • While the index works, a pill in the status bar says so. Click it to open the Search slide.
  • A draft enters the index once you save it into the workspace.

Settings → This workspace holds the index controls:

SettingDoes
IndexShows the index's state, and Rebuild index builds it again.
Semantic search, Embedding modelSee below.
Excluded directoriesDirectory names to leave out at any depth, added to the global exclusion list.
chan-reportsCode reports: languages and line counts. On by default.

Settings → Search → Search indexing sets how hard the indexer works: Conservative, Balanced (the default) or Aggressive.

Semantic search

Search ranks content by its words. Semantic search, off by default, adds a ranking by meaning to it.

  1. Choose a model

    In Settings → This workspace, pick one under Embedding model, or keep the default.

  2. Turn it on

    Turn on Enable semantic search (Hybrid mode). chan downloads the model first when it is not on disk.

  3. Let it finish

    The index embeds the workspace's content. The status bar counts what it has embedded until it is done.

Details and limits
  • When a search, the graph or a file report is missing something, check the Search slide and Settings → This workspace.
  • The index skips what ignore rules and excluded directories leave out. Code reports are kept apart from the embeddings.
  • cs dashboard --carousel-index picks the first slide: 3 Metrics, 0 Workspace, 1 Search, 2 About.
  • The process samples itself once a second and keeps the last ten minutes, whether or not a Dashboard is open, so a Dashboard opened later shows the minutes before it.
  • The chan home is measured once a minute, and only while someone reads the metrics.
  • Until the first sample arrives, the cards read n/a with a waiting message. A reading the platform cannot give reads n/a.
  • A failed storage scan reads Storage scan failed with the reason. The last completed total stays, marked as such; with none, the sizes read n/a and the time Scan pending.
  • The slides rotate every 5 seconds, and not while their tab is hidden. One slide always stays shown.
  • --carousel-off belongs to the one tab; other Dashboards keep rotating.
  • A control terminal and a tmux window's panes draw no tab strip and take no Dashboard.
  • The default embedding model is BAAI/bge-small-en-v1.5. In the command launcher, Semantic search asks before it downloads a model.
  • A chan built without the embedding model says so under Semantic search and offers lexical search only.
