Five layers

chan is one binary that runs in five layers. Each runs on the one before it and adds to it, so you can stop at any of them.

LayerWhat runsWhat it adds
1. A workspacechan serve PATHOne workspace in a browser: terminals, editor, file browser, search, graph and cs.
2. A libraryChan Desktop's built-in server, or chan devserverMany workspaces, standalone terminals over the whole machine, and the Computers screen.
3. Chan DesktopThe desktop appNative windows, the chan-term, chan-files and chan-edit commands, and default apps.
4. A devserver elsewherechan devserver on another machineThe same library, reached by address, by a connect script such as ssh, or from a browser. It keeps running when you disconnect.
5. A gatewayServices you hostSign-in, sharing, and an always-on address for each devserver.

Workspace

A workspace is a directory chan treats as a project, with search, an editor, a graph and agent teams over it. What chan derives from it lives under the chan home, ~/.chan, never in the directory. chan serve PATH opens one, in your browser when no Chan Desktop or devserver runs. See Workspaces and chan serve.

Windows, panes, tabs and sides

A window holds panes; each pane has two sides, A and B, each a strip of tabs. A tab is one app, such as a terminal or the editor. Windows belong to the server, so a window can reload, hide, or show on another computer while its shells keep running. See Windows, panes and tabs.

Library

A library is everything one chan server holds under a chan home: workspaces, standalone terminals and windows. Chan Desktop runs one on your machine, and each devserver runs one. A standalone terminal is a window with no workspace, whose file browser and editor reach the whole machine. See Standalone terminal, files and editor.

Computers screen

The Computers screen lists this machine, each devserver and each tmux connection, with their workspaces and windows. Chan Desktop slides it in over any window; a browser at a devserver's address shows the same screen. See Computers screen.

Chan Desktop

Chan Desktop is the app: it runs a library on this machine and shows its windows, and your devservers' windows, as native windows. It installs chan, cs and, outside Windows, chan-term, chan-files and chan-edit. On Linux it can be your default terminal, file browser and Markdown editor.

Devserver

A devserver is a library running headless on another machine, as a user service that chan devserver start installs, behind a token. Chan Desktop reaches it by an address and a connect script, such as ssh -L, and a browser by its URL. Disconnecting leaves everything running there. See Remote overview and Run a devserver.

Gateway

A gateway is a set of services you run yourself; chan is not an online service. A devserver dials out to it with a personal access token, and the gateway publishes it behind sign-in to you and the accounts you share it with. See Connect to a gateway, or Host a gateway to run one.
