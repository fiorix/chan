What you can do

  • Write a long prompt in Markdown over the terminal it goes to.
  • Paste a screenshot into it. The agent receives the image's path on disk.
  • Take back a message that is still waiting in the queue, and edit it.
  • Keep notes and their attachments as drafts, outside your project, until you save them.

Rich Prompt

The Rich Prompt is a Markdown editor floating over the bottom of a terminal, one per terminal. What you submit joins the terminal's queue, the one cs terminal write uses, so a message from elsewhere never lands in the middle of yours.

  1. Show it

    Press Cmd+Shift+P on macOS or Ctrl+Alt+P on Windows and Linux, or choose Rich Prompt from the terminal's right-click menu or the command launcher.

  2. Write

    Markdown renders as you type. A pasted image shows in place.

  3. Submit

    Press Cmd+Enter on macOS or Ctrl+Enter elsewhere. The strip reads 1 queued until the terminal takes the message, then the bubble clears.

Rich Prompt style toolbar, in the terminal's right-click menu and the command launcher, shows the formatting toolbar over the text while the bubble is open.

Submit sends the key the terminal's agent expects. A terminal started with agy, claude, codex, gemini, kimi, muse or opencode picks it by itself. For a launcher chan does not recognise, set CHAN_AGENT to one of those names; cs terminal write --submit=AGENT does the same from a script.

Details and limits
  • An image goes to the terminal as its absolute path on disk, which an agent can open. The bubble keeps showing the picture.
  • The bubble edits a draft of its own, so its text survives hiding the bubble and reloading the window.
  • While a message waits, typing starts the next one. Then ↑ recall in the strip, or Up in an empty bubble, takes the waiting message back to edit, and Esc in an empty bubble drops it from the queue.
  • The strip reads queue full, try again when the terminal's queue is full, and connection lost, message may still be queued when chan cannot confirm the send.
  • Drag the bubble's top edge to resize it. It reopens at that height.
  • For an agent started by hand at a shell prompt, chan picks the submit key from the keyboard mode the agent turns on.
  • Group broadcast does not copy Rich Prompt messages to other terminals.
  • The Rich Prompt needs a window that holds drafts: any workspace window, or a standalone terminal window whose machine serves files. A devserver's control terminal has none.

Drafts

A draft is a Markdown note with a folder for its attachments, kept outside your project until you save it. The Rich Prompt writes into one too.

  1. Create one

    Choose New draft from a pane menu or the command launcher. The first is Drafts/untitled/draft.md, the next Drafts/untitled-1/draft.md, and so on.

  2. Write, and come back later

    Pasted images go in the draft's folder. The file browser lists drafts in its Drafts group; open one from there to keep editing.

  3. Close it

    Closing its tab asks what to keep.

Details and limits
  • A workspace keeps its drafts in chan's data for that workspace, outside the project directory. The Drafts/... path shown is not a path in your repository.
  • Drafts stay out of search and the graph until you save them into the workspace.
  • A directory named Drafts that you create in your repository is ordinary project content.
