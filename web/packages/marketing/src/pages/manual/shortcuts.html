Change a shortcut

  1. Open the list

    Open Settings → Keyboard Shortcuts, and type in Filter commands to narrow it. Each command has a column for Web, macOS, Linux, and Windows; this device marks yours.

  2. Press the new keys

    Click a command's key cell, or Assign where it has none, and press the keys. A shortcut needs Cmd, Ctrl, or Alt; Esc cancels.

  3. Settle a conflict

    Keys another command holds show In use by and its name. Where trading keys works for both, Swap exchanges them.

Details and limits
  • The x beside an assigned key returns the command to its default.
  • Any column can be filled from any machine, to prepare another system's keys.
  • A shortcut saved for a command chan no longer has is dropped when a window loads, and the status line says how many were dropped.
  • On Windows, AltGr is Ctrl+Alt. Where your layout's AltGr types a character on a key, such as AltGr+S on Polish, Ctrl+Alt with that key types the character instead of running its shortcut; assign that command another key.
  • Letter keys follow your keyboard layout; digit keys follow their position.
  • A command with no default key, such as Group broadcast off macOS, gets one only here.
  • In a browser on Windows or Linux, the browser may keep Ctrl+Shift+T for its own tabs. Hybrid Nav's t also opens a terminal, or assign New terminal another key.
  • chan config does not edit shortcuts; use Settings.
