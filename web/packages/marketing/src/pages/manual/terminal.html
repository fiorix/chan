What you can do

  • Open terminals as tabs, and name them so you and your scripts can find them again.
  • Find text in a terminal's scrollback, newest match first.
  • Copy a long wrapped command as the one line it is.
  • Type into every terminal of a group at once.
  • See what each terminal is running from the pane tree.

Terminal tabs

Choose New terminal from a pane menu, the command launcher, or Computers, or press Cmd+T on the macOS desktop and Ctrl+Shift+T elsewhere. Moving, splitting and closing tabs is in Windows, panes and tabs.

Details and limits
  • Renaming or regrouping a running terminal applies at once, but its shell keeps the old $CHAN_TAB_NAME and $CHAN_TAB_GROUP: the tab menu reads stale env and offers Restart terminal.
  • Two terminals can share a name. A cs command that selects by name reaches both.
  • On Windows, where chan finds several shells (PowerShell, cmd, Git Bash, WSL), the pane menu lists them under New terminal, and the command launcher has New terminal with profile.
  • Most browsers keep Ctrl+Shift+T to reopen a closed tab. Use the pane menu, or bind another key in Keyboard shortcuts.

Find in a terminal

With a terminal focused, press the find key or choose Find from its right-click menu. The bar searches the scrollback as you type and selects the newest match, the one nearest the prompt.

2 of 7The second newest of seven matches is selected.
0 of 0No match.
2 of 40+The scrollback is still being searched; the total can grow.
? of 7No match is selected. The next step starts from the newest match with Enter, or the oldest with Shift+Enter.
Details and limits
  • Off macOS a plain Ctrl+F stays with the shell.
  • Steps wrap around at both ends.
  • On Windows and Linux, Ctrl+G steps only while the keyboard is in the find bar. In the shell it is the bell character.
  • A browser steps with Enter and Shift+Enter only.
  • The query is kept for the next time the bar opens. A restart that replaces the terminal closes the bar.
  • With the ghostty engine, the default, a resize keeps the selected match. A resize that removes it, as narrowing a full-screen program can, leaves no match selected.
  • Heavy output into a long scrollback restarts the search for a moment, shown as + and ?. If it has not caught up after about a second, or the output pushes the match out of the scrollback, no match stays selected.
  • On the xterm engine (Terminal engine (new terminals) set to xterm in Terminal settings) the bar counts up to 1000 matches and then reads ? of 1000+.

Copy and paste

A line the terminal wrapped at its right edge copies as one line, so a long command pastes as the command it is. Line breaks a program printed stay.

Copy the selectionCmd+CCtrl+Shift+C
PasteCmd+VCtrl+Shift+V
Select a word, or a whole lineDouble click, or triple click. A triple click takes a wrapped line whole.
Copy all of the outputCopy scrollback in the right-click menu. That menu's Copy does the same when nothing is selected.
Paste the PRIMARY selectionMiddle click, on the Linux desktop
Copy from a scriptgit log -5 | cs copy. See Clipboard.
Paste into a filecs paste > shot.png
Details and limits
  • With the ghostty engine, the default, a mouse selection, a double click and a triple click also copy to the clipboard.
  • On the Linux desktop a selection also sets PRIMARY, and a middle click pastes PRIMARY on either engine, including text selected in another application. Copy keys and the menu's Copy use the regular clipboard.
  • In a browser, selection and middle click follow the browser.
  • With the ghostty engine a paste cannot end the bracketed paste a program asked for: escape, NUL, backspace, delete and the control characters such as Ctrl+C, Ctrl+Z, Ctrl+U and Ctrl+W arrive as spaces. Tabs stay.
  • On either engine every pasted line break arrives as the carriage return Enter sends.
  • cs copy and cs paste use the clipboard of the machine viewing the window, so they work from a devserver terminal too.

Group broadcast

Group broadcast sends what you type in one terminal to others of its group, to run one command in several shells at once.

  1. Put the terminals in one group

    Right-click each tab and type the same name in Group, or run Set terminal group.

  2. Choose the targets

    In a tab's right-click menu, under Broadcast targets, turn on Group broadcast to check the whole group, or check single terminals. The command launcher has both rows; on the macOS desktop Cmd+Shift+I toggles the group.

  3. Type

    What you type in a checked terminal reaches the other checked ones. A radio icon on the tab says how many tabs it reaches.

BroadcastNot broadcast
Typing, pastes, dropped file paths, mouse and wheel inputRich Prompt messages, and replies the terminal sends by itself, such as focus reports
Details and limits
  • Broadcast never leaves the group, nor the workspace or the standalone terminals it belongs to.
  • The menu lists the group's terminals in other windows under other windows. Each receives only while its own box is checked.
  • Windows, Linux and browsers have no default broadcast key. Bind one in Keyboard shortcuts.
  • cs terminal write --tab-group web sends text from a script, queued until each terminal is idle. No cs command turns broadcast on or off.

What each terminal runs

The pane tree, Cmd+Shift+A on macOS and Ctrl+Shift+A elsewhere, shows what each terminal runs beside its name: the title the program in front set, else its name, such as vim or cargo. The tab keeps its own name, and cs finds it by that.

Details and limits
  • A title lasts while the program that set it stays in front. When that program ends, the row reads the command again; an earlier title does not come back.
  • Every window and browser tab attached to the terminal shows the same text.
  • A program that starts and ends within a moment may never show, and a title set just before a program ends can stay on the shell until the next program starts.
  • Over ssh the row reads ssh, or the last title the remote side set.
  • On Windows the row shows titles only.
  • In privacy mode the row reads Hidden, and the pane tree's filter matches tab names only.
  • A tmux window's rows show the command each pane runs instead. See tmux control mode.

tmux control mode: tmux -CC

Run tmux -CC in a Chan terminal, locally or over ssh, and each tmux window opens as a Chan window with tmux's panes. It is off by default and has a page of its own.
