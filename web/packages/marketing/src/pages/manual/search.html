Search the workspace

Open Search from the command launcher or Search workspace in the pane's hamburger menu, or use Cmd+Shift+S on macOS and Ctrl+Alt+S on Windows and Linux. Search content, filenames, tags, and other indexed workspace entities from one place.

Choose a result to open it, and use Details for information about the selection. Content matches carry snippets so you can judge the result before opening the file. Search depends on the workspace index; check the indexing view if newly added content has not appeared yet.

Search from a terminal

cs search queries the current terminal's workspace and prints results without opening a tab. Use it for content search, browsing entities, or following graph connections:

$cs search retry backoff {{copyButton}}
$cs search --domain tag {{copyButton}}
$cs search --from file:notes/design.md --depth 2 {{copyButton}}
$cs search --from language:Rust --edge-kind language --json --pretty {{copyButton}}

Selectors use type:value, including file, directory, tag, mention, contact, and language. --domain limits the kinds of results, and --from starts traversal from an exact entity. Language queries need code reports. Run cs search --help for limits and direction controls.
