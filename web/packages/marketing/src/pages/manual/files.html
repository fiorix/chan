What you can do

  • Browse a workspace, or the whole machine from a standalone terminal's window.
  • Open files in the editor, and images, audio, video, and PDF in a viewer.
  • Copy, move, rename, and delete files from the keyboard, with standard or Vim keys.
  • Upload files from the machine you are at, and download files and folders to it.
  • See how much code a folder holds, by language, with a COCOMO estimate.

Browse

Open oneHow
In a tabNew file browser, from the pane menu or the command launcher, or cs open . in a terminal.
Docked beside the panesLeft file browser dock or Right file browser dock, in a workspace window. A dock shows a tree.
  • A Files tab shows one folder, with breadcrumbs, back and forward, a path field, and a name filter.
  • Sort by Name, Kind, Size, or Modified. Folders stay first.
  • Double-click a folder to enter it, or a file to open it.
  • Details, in the toolbar or the file browser's menu, shows the selection.
  • Drag rows onto a folder to move them, or drag a file into a pane to open it there.
  • Hidden files shows names that start with a dot.

In a workspace window the browser shows the workspace, with its unfinished documents in a Drafts group above the files; see Drafts. In a standalone terminal's window it shows the machine's filesystem.

Upload and download

Upload opens a picker on the machine you are at, and download saves there. Progress shows in the Transfers panel, which opens from Transfers in the status bar; one upload is one row, however many files it carries. A browser shows a download in its own downloads list.

You chooseWhat happens
Upload, from the file browser's menu or the command launcherUploads into the folder a Files tab shows. In a dock: into the selected folder, or the selected file's folder; with nothing selected, the workspace root, or your home folder in a standalone terminal's window.
Upload in a folder's DetailsUploads into that folder.
Upload on a file, in its right-click menu or its DetailsReplaces that file.
DownloadSends a file as it is, and a folder as a tar archive.

From a terminal, cs upload and cs download do the same: see Transfers.

Code reports

Details on a source file shows its language and line counts. On a folder it shows the totals for everything under it, by language. The workspace's totals are on the Dashboard.

FieldMeans
indexedThe files counted.
SLOCLines of code.
comments, blanksComment lines and blank lines.
complexityA count of branching keywords and operators. A heuristic, not cyclomatic complexity or a judgment of quality.
A language rowIts files and lines of code. Choose the language to open it in the graph.

Reports are on for a new workspace. Turn them off or on in Settings → This workspace → chan-reports, or with chan workspace reports disable --path PATH and enable --path PATH. Off deletes the report data; on builds it again.

COCOMO estimates

A folder's report, and the workspace's, end with a Basic COCOMO estimate made from the lines of code. It models what writing that code would take. It is not a record of time spent, nor a forecast for your team.

Details and limits
  • Selecting another row keeps a closed Details closed.
  • A dock has no Details; there Cmd+Y or Ctrl+Y opens the selection in a tab.
  • Backspace deletes too.
  • Vim keys work while the list or tree has focus, and the choice is saved in this browser.
  • Files dragged in from another application are not uploaded; use Upload.
  • On Chan Desktop an upload's row appears while the picker is open, and offers Cancel once you have chosen; closing the picker leaves no row.
  • A cancelled upload reads Upload cancelled; a failed one names the file and the reason, never the folder it came from.
  • Uploading over a text file refuses bytes that are not UTF-8.
  • Counts follow the workspace's included files and update as files change.
