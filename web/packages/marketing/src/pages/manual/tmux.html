What you can do

  • Run tmux -CC locally or over ssh. Each tmux window opens as a Chan window, with its panes laid out as tmux has them.
  • Split, resize, and close panes with Chan's shortcuts and Hybrid Nav. tmux does the work and owns the layout.
  • Manage the connection from its card on the Computers screen: new window, show, hide, detach.
  • Detach and come back later. The tmux server keeps running.
  • Script the panes with cs terminal list and cs terminal write, like any other Chan terminal.

Turn it on and connect

  1. Enable tmux control mode

    It is off by default. Turn it on in Settings → Terminal → tmux control mode (tmux -CC), or from a terminal. tmux 3.2 or newer is required.

    $chan config set terminal.tmux.enabled true{{copyButton}}

  2. Start tmux in a Chan terminal

    On this machine:

    $tmux -CC new -A -s dev{{copyButton}}

    On another machine, over ssh:

    $ssh -t user@host tmux -CC new -A -s dev{{copyButton}}

  3. Answer the banner, if one shows

    A tmux you ran directly connects at once. When another program is in front, such as ssh or Eternal Terminal's et, a banner names it and asks: Allow, Allow for this tab, or Deny. No answer in 60 seconds is a deny.

To skip the question for a program you run as a habit, list its name under terminal.tmux.trust in server.toml:

[terminal.tmux]
trust = ["ssh", "et"]

Windows and panes

  • Each tmux window is a Chan window of its own. Its panes are tmux's panes, split as tmux lays them out.
  • The desktop opens the first eight windows at connect; the rest are listed hidden on the card. In a browser, open each window from its row with Open window.
  • A pane has no tab strip and no A and B sides. With tabs in the title bar, a tmux badge takes the A/B button's place.
  • A pane is named after the command running in it: bash at a prompt, top while top runs.
  • These windows are not saved. They last as long as the connection.

The connection's card

A connection is a card on the Computers screen, beside this machine and your devservers. Its rows are the connection's windows.

The card is titledWhen tmux runs
tmux -CC on this machineIn a terminal of this machine.
tmux -CC on and the devserver's nameIn a devserver's terminal.
tmux -CC from ssh geekomBehind another program, here ssh geekom.
  • t asks tmux for a new window, and o detaches.
  • Each row focuses, shows, or hides its window. Hiding the last shown window detaches.
  • The terminal that ran tmux -CC is the card's control terminal. It takes no typing while connected.

Details and limits
  • Every window attached to the terminal shows the banner, and the first answer wins. A deny writes one newline, which detaches a real tmux.
  • A peer that does not answer like tmux, or a tmux older than 3.2, is detached with a note in the terminal.
  • Turning the setting off leaves a running connection alone. tmux itself is always trusted.
  • On the desktop the control terminal moves to a hidden control window while connected, and returns as an ordinary terminal window when the connection ends. In a browser it stays a tab in its window.
  • A new pane reads as its tmux id, such as tmux %3, for about a second, until tmux reports its command.
  • cs terminal list lists the panes in the tmux group. Session names are unique, so two panes at a shell are bash and bash-2 there.
  • A label you give a window in Computers replaces tmux's name for it until you clear the label. It does not last across a reconnect.
  • A window moved with tmux's own move-window or swap-window keeps its Chan window and panes.
  • A divider between nested splits that no single pane's resize reaches does not drag.
  • Hybrid Nav stages no tabs and swaps no tiles in a tmux window, and its Tab does nothing there.
