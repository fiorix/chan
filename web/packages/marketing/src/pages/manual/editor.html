What you can do

  • Write Markdown that renders as you type, and switch to its source when you need the syntax.
  • Link files with [[, mention people with @@, tag with #, and insert dates with @today.
  • Paste or drop images into a note. They are saved beside it.
  • Edit any text file in the source editor. Files stay ordinary files on disk.
  • Leave saving to the editor: it saves as you pause, and asks when another program changed the file.
  • Jump through a long document with the outline, and see a file's links and backlinks in Details.

Saving

The editor saves a file shortly after you stop typing. Two states stop the save and ask you.

External edit detected

Another program changed the file since the tab read it.

ChoiceWhat it does
ReloadTakes the file as it is on disk and discards the tab's unsaved edits.
OverwriteWrites the tab's text over the file.
CancelKeeps the edits in the tab, unsaved.

File moved or deleted

The file went away while it was open. Unsaved edits stay in the tab, and every choice keeps them.

ChoiceOfferedWhat it does
Save hereWith unsaved editsWrites them to the same path, recreating the file and its folders.
Re-openWith nothing unsavedReads the file again, or lets you pick where it went.
Re-open thereWith nothing unsaved, when one file of that name turned up elsewhereOpens that file.
FindAlwaysSearches the workspace for a line of the file.
CloseAlwaysCloses the tab, asking before it discards edits.

Write Markdown

TypeYou get
[[A picker of the workspace's files. It writes [[file]].
[[file#A picker of that file's headings.
@nameA contact picker. It writes a link to the contact's note.
@@nameA contact picker. It writes an @@name mention, which the graph ties to the contact.
#A picker of the tags already in the workspace.
![An image picker. It writes ![](path).
@today, then SpaceToday's date, as a date pill.
@date, then SpaceThe same, with a calendar to pick another day or format.
  • ![](path) embeds media inline, SVG images and .excalidraw drawings included.
  • Paste an image, or drop image files from your file manager, to save them in the note's folder and embed them at the caret or the drop.

Contacts and other kinds

A chan: block in a note's frontmatter says what the note is. kind: contact makes it a contact: its own kind of node in the graph, and what @ and @@ find. The optional aliases are the names @@ mentions match.

---
aliases: [jq, jdoe]
chan:
  kind: contact
---

kind: slides makes a note a slide deck; see Slide decks.

Details and outline

Each of these is an on/off row in the command launcher's Editor scope.

RowShows
OutlineThe file's headings. Choose one to jump to it, in the rendered or the source view.
DetailsThe file's size and modified time. In a workspace window, also its links and backlinks.
Style toolbarFormatting buttons over a Markdown file.
Source modeThe file's text in place of its rendered view.
Details and limits
  • A save that fails shows Not saved: and the reason at the top of the tab.
  • A draft that was discarded or saved elsewhere reads This draft no longer exists and offers only Close.
  • @today, @date, and @pagebreak expand on Space or Enter as you type in the rendered editor; written into a file any other way, they stay plain text.
  • Typed inside code, inline or fenced, a trigger stays text.
  • A written date such as 2026-07-23 or 13 April 2024 also shows as a date pill.
  • A mention holds only letters, digits, _, and -, so an alias with a space never matches.
  • Import contacts, in the file browser, and chan workspace contacts import csv write one contact note per row of a Google Contacts CSV.
  • Ctrl+E in a focused terminal stays the shell's end of line; Source mode acts on the active file tab.
  • The outline is offered for a file with headings, and the style toolbar for Markdown.
