Install

Download Chan Desktop for macOS, Windows or Linux from the install page, which also lists each platform's packages and the chan command for servers. On a Mac it needs macOS 14 (Sonoma) or later, and it refuses an update that needs a newer macOS, keeping the installed app.

First run

  1. Open Chan Desktop

    It opens a standalone terminal: a window with no workspace behind it, titled Terminal Window 1, with your shell in your home directory.

  2. Show the Computers screen

    The screen slides in over the window and lists this machine, your devservers and every window. Press the same key, or Esc, to go back.

    TomacOSWindows, Linux
    Show or hide the Computers screenCmd+P, or View → ComputersCtrl+Shift+P

  3. Open another terminal

    New terminal on This machine's card opens another standalone terminal window, listed under Terminals on the card.

  4. Make a workspace

    New workspace turns a directory into a workspace, with search, an editor, a file browser and a graph over it. Or run this in a chan terminal at the root of a project, such as a git repository:

    $chan open .{{copyButton}}

    The workspace appears under Workspaces on This machine's card. The New window button on its row opens a window of it; a pane's menu lists the apps a tab can open.

Details and limits
  • On Windows and Linux the window's menu bar, with the same View → Computers item, shows only while the Computers screen is open.
  • Inside a git repository chan open expects the repository's root; add --here to open a subdirectory.
  • Quit and reopen Chan Desktop and your windows and layouts come back. Terminals on this machine keep their layout and start fresh shells.
  • Starting Chan Desktop while it runs opens no second copy: the running one comes forward, and opens a terminal window when none is shown.
