What you can do

  • Set the theme once for every app, and override it in each app's section.
  • Tune the editor, terminal, file browser, graph and search.
  • Choose what this workspace indexes, and lock it when you step away.
  • Hide names, addresses and paths while you record or share your screen.
  • Read and change the same settings from a shell with chan config.

Configuration from the terminal

chan config reads and writes the same settings on the machine where it runs. It needs no running chan, and open windows pick up a change at once.

$chan config get terminal.program_status{{copyButton}}
$chan config set terminal.program_status true{{copyButton}}
FormDoes
chan config getPrints every setting as TOML, or JSON with --json.
chan config get KEYPrints one value.
chan config set KEY VALUEChecks the value, saves it and prints it back. KEY=VALUE also works.

editor.* keys live in preferences.toml and server.* keys in server.toml, both in ~/.chan. CHAN_HOME names another directory for all chan state, such as for an isolated devserver beside your desktop.

Privacy mode

Turn on Settings → Global → Privacy mode before you record or share your screen; a recording does not turn it on. While it is on, chan hides:

  • On the Computers and Gateways screens: computer and gateway names, addresses, connect scripts and tokens, workspace paths, WireGuard file paths and public keys, connection errors, notices and action details.
  • Window labels. Computers lists each window by its generated name, such as Terminal Window 2, and window titles read Chan (privacy mode).
  • In the command launcher's Computers rows, names: each window reads Window, each workspace Workspace, each computer Computer.
  • On the Dashboard: the host name, chan home path and storage scan errors on Metrics, and the root path on Workspace.
  • The program each terminal runs, as the pane tree lists it.

An eye button beside a hidden field reveals that one field. What a terminal prints and what a file contains are not hidden; turn on Mask terminal secrets in privacy mode to mask secret-looking values in every terminal while privacy mode is on.

Details and limits
  • Privacy mode belongs to whoever is looking: Chan Desktop applies it to all of its windows, a devserver's included, and browser tabs at the same address share it.
  • With tabs in the title bar, the bar names the window by its generated name alone.
  • When privacy mode goes off, each terminal goes back to its own secret masking.
  • This workspace, and the left and right file browser docks, show only in a workspace window. Title bar tabs show only in Chan Desktop.
  • On the Linux and FreeBSD desktop a key binding cannot use the Super (Windows) key, which the desktop's web view does not report as a modifier.
  • terminal.* is short for server.terminal.*. An unknown key is an error that lists every key you can set.
