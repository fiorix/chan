# tmux control mode captures

Raw bytes a `tmux -CC` client reads from its PTY, recorded with tmux 3.8 by `capture.py` and `forged-end.py` inside a throwaway sdme guest (private socket per scenario, 80x24 client unless the scenario resizes). The `3008` OSC lines are the guest bash's systemd context marks; machine, boot and process ids are zeroed. Scenario 05 (a 2.7 MB pause-after run) is regenerated by `capture.py` and not kept.
