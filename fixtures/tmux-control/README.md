# tmux control mode captures

Raw bytes a `tmux -CC` client reads from its PTY, recorded with tmux 3.8 by `capture.py` and `forged-end.py` inside a throwaway sdme guest (private socket per scenario, 80x24 client unless the scenario resizes). The `3008` OSC lines are the guest bash's systemd context marks; machine, boot and process ids are zeroed. Scenario 05 (a 2.7 MB pause-after run) is regenerated by `capture.py` and not kept. Scenario 14 (the pane names subscription) was recorded by `pane-names.py` on a host with no tmux configuration, its panes running `sh`; the host's name, which tmux gives a new pane as its title, is replaced by one of the same length. Scenario 15 (the same subscription while a shell titles its panes) was recorded by `shell-titles.py` with tmux 3.6 in an sdme guest whose host name was set to `tmuxvm`: each pane runs bash with the prompt hook Arch's `/etc/bash.bashrc` installs in a tmux terminal, which titles the pane `user@host:dir` with OSC 0 at every prompt, and one pane runs `top` under that title.
