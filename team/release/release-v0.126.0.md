# Release v0.126.0

Shipped 2026-11-08 from `0.126.0-ga`: the release commit (the pins moved from `0.125.0` to 0.126.0 in the ten manifests, the three lockfiles regenerated, both Nix hashes harvested, the Fedora specs, the rows moved to `done/`, the CHANGELOG section, the release index line and this record) on the round's integration branch `v0126/int` over its final tip `064d54d4a`. No release candidate was cut: the owner released from the integration branch on his word ("GA from here, if all green") once every check on that tip was green.

The release opened on 2026-11-07 at the v0.125.0 close with six items that release's readings and proofs found, and on 2026-11-08 the owner added six found while writing the chan.app tutorials, then moved every item of medium size or larger to v0.127.0 by his word ("all M, L, and XL move to v0.127; the only M stayign in v126 is wakevis"). The owner's title bar work, written and tested on his Mac and built for Windows, joined the round as two rows the lead committed from the Mac agent's report, and his own small branches landed through the same review as the team's: the `chan close` repair, a new row for Cmd+P over a reconnecting window, and the wakevis reading procedure. A four-seat team built the rest: @@Gw126 (Codex Astra) the gateway and account items, @@Desk126 (Codex Sol) the CLI help, the Windows preflight and the document drift, @@Win126 (Claude Opus) the Windows VM build, tests, four fixes and the owner's acceptance run, with @@Lead126 (Claude Fable) reviewing every range, running every gate and guest proof and merging.

## Retrospective

Highlights: thirteen rows, six of them on the owner's branches, through one review path in one day, with the title bar's default flipped on the owner's word and read on both platforms the same evening; every red of the integration gate attributed, by a rerun at the same sha or a reading of the merged code, rather than read as a verdict; the zone scenario proving the account page's command end to end against the real gateway stack in a guest the lead built in ten minutes.

Lowlights: three integration gate runs red: int gate 2 on time-bound tests in two of its steps under the load of four gates and two guest builds on one 16-CPU host, int gate 3 on a lock-timing test at low load, both with the base's code, and int gate 7 on the composition of the title bar and privacy mode branches, caught by a source-reading test at the merge and fixed in one commit on the integration branch; each cost a 25- to 45-minute run; the lead's own slips (a long sha typed from memory, stamps ahead of the clock, a push guard reading an empty variable from a piped group), each caught by an instrument; two recycles of the Codex gateway seat at commit boundaries.

Honest feedback: the host rule's letter ("no smoke or test server") and the orders' host-command list disagreed on the marketing check; the lead ruled on the rule's purpose and left the wording to the owner.

- Windows, read by Win126 outside the title bar branch: Alt+F4 with a terminal focused does nothing in either mode (the terminal takes the key); a window hidden while maximized reopens un-maximized at the maximized rectangle, its frame under the taskbar; the default cascade places a new window's bottom under the taskbar; a blank grey-titled window shows for under five seconds at a build's first start; every local window's console logs a `gateway_csrf_token` ACL refusal at load.
- macOS, read by the owner's agent: a page that paints no background, such as the embedded server's JSON at `/api/health`, shows the desktop through the transparent chan window and the window loses its shadow, whatever the title bar setting; a chan-desktop build run outside the isolation function signs with the keychain's Developer ID identity in spite of the CI config's ad hoc `-`.
- The title bar's back-forward-cache re-ask runs on macOS only: WebView2 reloads the app on a step back (a page holding WebSockets stays out of Chromium's cache), so Windows reaches the mode by the boot path; one line for the title bar rows' Boundaries.
- Every launch that starts the embedded server saves the desktop config and serializes every field, so a home a build has run on pins `titlebar_tabs` and a later default would not reach it; a design question for a default-valued field left out of the file.
- Settings > Global > "Empty-pane carousel" names a surface the Dashboard tab now owns (the carousel renders only there and its play/pause button writes the same preference); rename the row and, while chan is pre-release, its key.
- The host rule's wording on `make web-marketing-check`, a Node loopback static server over the built site that the orders list as a host command; the lead ruled it a host command and leaves the rule's wording to the owner.
