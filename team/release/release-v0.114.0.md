Shipped 2026-10-28 as the one GA commit on `0.114.0-ga` over `b7156cccd`, which descends from the base `0604056a2`, the tip of `main` (the v0.113.0 publication record and the WINCH reporter fix). Above the base stand the commits of `v0114/launcher-docs-and-keys` and one merge, `568f8eeca`, of the owner's `v0114/bsddsk` at `48a8f7f66` (two commits, `09148141f` and `48a8f7f66`). The version ships all seven of its rows with no release candidate, by the owner's words "proceed to ga and tag; fully automated, i wont be able to babysit". The Super row moved to v0.115.0 by the owner's word before the GA.

The other six rows were raised on 2026-10-27 from the owner's words while one session rewrote the manual's Computers screen pages: the Rich Prompt chord and the AltGr rule were built in that session, then the window counts, the Computers chord and the two manual mock rows were built by agents in their own worktrees on the owner's word "you can spawn sub-agents to implement these, and then come back", and merged and verified by the session. The window counter row's server and config cleanup followed on the owner's question "what's blocking to clean it up already?".

## What shipped

- `bsddsk`, chan-desktop has no FreeBSD build though its toolkit supports FreeBSD: `Cargo.lock` takes tao 0.37.2, the FreeBSD workflow checks `chan-desktop` again and the manual's Install page has the build-from-source steps (`09148141f`). On macOS 0.37.2 frees the window objects 0.37.1 over-retained on close; its rewritten key and IME code is off chan-desktop's key path, which runs through wry's WKWebView, and the owner read the release bundle on macOS ("it all worked from my tests").
- `rpchrd`, The Rich Prompt's Ctrl+Shift+P never fires on the Linux and Windows desktop: off macOS the Rich Prompt is Ctrl+Alt+P on native and web, and Ctrl+Shift+P stays Toggle Launcher (`a75b8ffe5`); `chan serve --help`'s keybindings table and `cs`'s Rich Prompt help name the new chord (`b7156cccd`).
- `altgrw`, Ctrl+Alt chords may be refused as AltGr typing on Windows: off macOS an AltGraph keydown is a chord when Ctrl and Alt are held and the key is still its plain ASCII letter or digit, and text entry otherwise, in `web-shared`'s `shortcutKey`, the desktop key bridge and the echo extension's reference relay, with the extension contract in `docs/extensions.md` (`0119a1912`); the manual names the Windows caveat. The Windows measurement stays open by the owner's decision.
- `wincnt`, The launcher's window counters are collapse toggles: the counts are plain text on machine headers and workspace heads and the chevron is the one expand control (`23a18cd60`); the collapsed-machines store, its `/api/library/collapsed-machines` route and the desktop config's `collapsed_machines` field are removed, and a config still holding the key loads and drops it at the next save (`a4cd897cf`).
- `cmpkey`, The Computers command launcher chord opens the same deck as the command launcher: the Cmd+Shift+K / Ctrl+Alt+Shift+K binding and the launcher's Computers entry mode are removed; the deck's session draft keeps its key, so a draft survives a reload (`51bf433fe`). The stale `docs/adr/0001` that described the entry modes is removed by the owner's word (`c02033978`).
- `dsdemo` and `mkdeck`, The Add devserver demo opens a dialog where the desktop flips the card, and The manual's launcher mocks size their cards by the reader's window: the devserver mock opens on the Add devserver card turned over to its form, and the mocks' deck height follows their frame through container query units, with the first-run mock at 540 px and the devserver mock at 800 px, accepted by the owner (`ae2793c08`).

Beside the rows: the manual's Install, Navigation and Devserver pages describe the Computers screen as the toggled launcher with its cards, keyboard map, gateways and the command launcher's Computers scope, and the live mocks fill the content column (`b0a1fbfd2`); and chan-server's WINCH reporter test no longer uses a command substitution, which Ubuntu 24.04's bash 5.2 aborts on when a resize signal lands inside it (`0604056a2`, on `main` before the cut).

## Retrospective

Highlights: a docs pass over the Computers screen found the manual describing a first-run screen the desktop no longer shows and, behind it, a Rich Prompt chord that could never fire on the Linux and Windows desktop; each finding became a row the owner decided before anything was built, and the four launcher and mock rows were built in parallel in worktrees on disjoint files and verified together.

Lowlights: the session started building the AltGr rule while the owner meant it as a roadmap row; the owner kept the work, but the request and the row should have been told apart before code. The WINCH flake did not reproduce at the test level at all, so the fix rests on a shell-level reproduction rather than on the failing test.

Honest feedback: a finding raised in conversation is a row until the owner says build. A flake whose cause is in a tool's version (bash 5.2 on the runner, 5.3 on the host) reproduces only on the runner's version; take that version's rootfs first.
