# Release v0.121.0

Shipped 2026-11-02 from `0.121.0-ga`: a no-rc release of eleven items, nine of them shipped, built on their own branches by four agents (the owner's macOS seat, the Linux seat and two agents on the Linux host), reviewed, gated and merged into `v0121/int` by the merger on the Linux host, and cut there on the owner's word ("go to ga and tag").

## What shipped

- `lastwin`, hiding the last shown window quits chan and kills the hidden windows' terminals: one rule in `desktop/src-tauri/src/last_window.rs` (shown windows other than the gesture's own, the library's live sessions summed over every mounted tenant, the gesture's own sessions) asked by every gesture that takes a window away: `cs window hide` and `cs window rm` with or without `--force`, the launcher's Hide, `h` and Close, the close prompt's Hide and Close, the close-window command and the command deck's Close window; `cs window rm` now asks the desktop before the host discards. The close of a window whose last tab closed stays outside the guard by the owner's word. Pinned by the rule's tests over a mock desktop with real PTYs, the control socket's order, the overlay, the launcher and the close-window paths (8 Rust and 6 web tests red with the guard removed). Not read on macOS (`836b84df7`).
- `confirmkeys`, keys pass under an open confirm: `modalDialogOpen()` withholds app chords, host commands and Hybrid Nav keys under a dialog, and the dialogs that answer a key stop it; Cmd+` passes. Pinned by eleven mounted cases (ten red on the base) (`e994b95a1`).
- `dndloss`, a window stops showing drop highlights: on macOS the hidden Computers launcher, a second webview laid over the window that AppKit still handed drags to, parks off the content while hidden; the source's `dragend` settles on the pane recorded at `dragstart`. Read by the owner in the desktop before and after ("it works"); stage 1 pinned by a mounted test (`fa56edc59`).
- `ghscroll`, Copy scrollback of a long ghostty history blocks the page: measured first (the per-row cost in Node and Chrome against ghostty-web's build and the core's one-call reads), then Copy Scrollback and every selection copy read through libghostty-vt's formatter in one call (55,000 rows at 200 columns in about 35 ms, from 3.6 s), and Select all selects the history and the screen; the owner chose the formatter over a rebuilt core (`01188e21d`).
- `cachixpins`, the Cachix publication keeps every release's pins: stable pin names with `cachix pin --keep-revisions`, the owner's option over an undocumented deletion route, a `cachix_keep` input defaulting to 10, a plan printed by dry runs, the helper's contract test in `make nix-hash-contract-check` (`31c5c0f8f`).
- `urlbubble`, the editor's URL bubble overlaps its label and outlives its tab: the label no longer shrinks in the external row (measured in Chrome, 3.1 px overlap before, 5.5 px apart after), and a `shown` signal apart from focus closes the editor's bubbles, calendars and previews when their tab is hidden, in a file tab and in the terminal's Rich Prompt (`1d76a73ef`).
- `forgetflake`, `chan close` can answer before the devserver records the workspace off: the reading found no reply-before-write race; the red came from a close that never reached the holding devserver and reported it not served. The close now looks for the lock's holder for five seconds and exits 1 naming the pid, and a holder that answers an error and keeps the lock fails the close (three tests red on the old code) (`62f4223c5`).
- `ghdelete`, Delete stops working in a ghostty terminal while typing still works: read in the code, the gap was delete input aimed at the renderer host, which ghostty-web focuses but reads delete input only on its textarea, and word deletes anywhere; chan's host listener now sends the four delete inputs once (eight of sixteen new tests red on the base). Not read on macOS, by the owner's word (`44f6f4592`).
- `tmuxnest`, a tmux divider between nested splits cannot be resized from chan: accepted as a limitation; the manual's tmux paragraph now states what v0.120.0 shipped (`762f95240`).

Closed with no code: `cmdbq`, Cmd+` does not switch chan windows on macOS: the owner's reading on the base found every focus cycling (`46d05c48f`). Carried to v0.122.0: `seethru`, terminal bodies turn see-through after an app switch, not reproduced (no macOS session), with the paint path read and a probe for the next occurrence (`cb0c14b04`).

A documents commit after each gated merge moved the item's row.

## Retrospective

Highlights: eleven items in one day from four agents on two machines, every range reviewed and red-proved on the Linux host, the Linux items merged while the macOS seat still worked, the pin patch and its Nix hashes built ahead of the cut. Lowlights: the merger's Rust intake ran fmt, clippy and tests but not rustdoc, so a doc link reached the merge gate and cost one round trip; hand-backs from the Mac arrived by tar file, an hour after their branches. Honest feedback: two items shipped on readings of the code alone (ghdelete, forgetflake on macOS), and seethru did not reproduce; each carries its probe for the next occurrence.
