# Release v0.88.0

GA 2026-08-10. Thirteen roadmap items delivered and one deferred, from the ten carried out of v0.87.0 plus four registered during the window. The release's defining result is that the browser smokes, made runnable for the first time, found an intermittent data-integrity defect on their first properly runnable execution, in the same path the previous release had hardened.

## What shipped

- **The browser smokes run in the project's own containers.** `scripts/e2e/browser-smoke` needed Chrome, and no machine in the normal workflow had it: the lane rootfs carries the Rust and Node toolchains and no browser dependencies, and the host carries no toolchain by policy. A provisioning target closes that, and the nineteen `networkidle2` waits are replaced by or justified against properties the page asserts. An environment that cannot run a check now exits 2 rather than being silently absent, following the flip-render harness convention that a skip is not a pass. **One acceptance line is honestly unmet**: `56-external-edit-matrix` scored nine of ten, and the tenth failure is the defect below rather than a flake in the check.
- **The defect those smokes found.** An external write to a file open in the editor with unsaved text leaves `GET /api/files/<path>` serving the old content and the editor buffer never converging. The v0.87.0 mtime CAS is not implicated and is holding: the external edit is never overwritten, and disk is byte-identical before and after the save. The conflict banner is on screen from the external write onward with both resolutions offered, so nothing is silently lost. The distribution is bimodal with no middle, converging between 516 and 610ms across three independent measurement sets or never converging at all, and the reproduction rate wanders on a timescale of hours with no code change. Registered for v0.89.0 with a preserved reproducer rather than repaired here.
- **`chan ps` answers what a workspace is doing.** Readiness, generation, required action, indexer status and queue depth are surfaced from the surfaces that already carried them, so the command cannot report a different truth than `/api/health` and `/api/index/status`. Diagnosing the v0.87.0 recovery stall previously took a shell, two tokens and hand-read JSON.
- **The boot overlay stops locking a workspace behind a healthy rebuild.** A recovery pass that is progressing no longer makes the workspace unusable, and search states that it is paused rather than returning an empty result set. Proven with `locked: false` while `state: recovering` across every sample, never once locked.
- **The Nix desktop package carries a real build id.** Both surfaces are fixed, not half: `chan-desktop` itself and the `chan` binary that same package ships and symlinks at `bin/chan`, which the flake's `src = self` had left stamping `unknown` because the store source has no `.git`. Verified on real Nix outputs, with two builds from different commits distinguishable by that id, and the assertion wired into the package smoke rather than eyeballed once.
- **A publish=false dry run exercises the path the tagged run takes.** Build tooling moves out of the cached `target/` tree into `.build-tools/`, so a step's behaviour can no longer depend on what a cache handed it. The v0.87.0 tag failed at a job its dry run had passed on the identical commit; the class is closed rather than the instance re-fixed, and the release skill records the second limitation next to the first.
- **`chan devserver --restart` stops destroying the tunnel registration it cannot read.** The endpoint requirement fired ahead of the code that recovers it from the installed unit, so a shell holding the token was refused outright and a shell without it silently rewrote a tunnelled service as a local one, destroying the only copy of the PAT. Exercised against a live supervised unit, in both directions.
- **The terminal's bundled face loads and its block glyphs fill the cell.** The `@font-face` src was absolute while every tenant mounts under a slug, so the face never decoded and `font-display: swap` hid it behind a system font that looked close enough. Block elements are drawn from cell geometry rather than deferred to the font. **Partial**: the xterm DOM renderer the Linux desktop ships still bands rules and blocks, and the WebGL present stall that keeps that renderer in place is unmeasured for want of a host. Both residuals carry forward.
- **The canvas animation family paints through WebGL2.** The whole family, including the point cloud host behind Lorenz Constellation, Rippled Duet, Striated Current and Twin Veil Dance, moves off 2D canvas paths that Linux software-rasterizes. Frames allocate nothing. Closed on the owner's observation of all four named animations plus the vortex and blooms running correctly on real Linux, Windows and macOS hardware, which is the measurement no harness in the round could produce.
- **Three load-sensitive `chan-server` tests, one cause.** `collect_until` drained only `handle.rx` and never `handle.replay`, while `Session::attach` subscribes at attach time and parks prior output in `replay`, so the harness was missing half of a contract production honours. One mechanism explains all three tests and explains why none of them contains a timing construct. The control-socket takeover test's fixed 25ms sleep is replaced by an observable release rather than a longer constant, and the `doc_sessions` external-edit staging no longer rides the filesystem clock.
- **The workaround audit ran.** Fifty-three sites marked across `crates/chan-workspace/src/`, seven findings recorded, and the sites found clean recorded alongside them so the pass carries a denominator. The greps that produced the population are written into the item with their blind spots stated.
- **An unverified lead was falsified rather than built against.** The hypothesis that one stalled workspace blocks turning off the others is not reproducible: closes do not serialize, do not exhaust the runtime, and are bounded. No code changed. The observation remains unexplained, with two candidate mechanisms ruled out and a third named and uninvestigated, and the item's contract stays permanently empty because there is no established cause to write one against.

## Process

One round, seven file-disjoint lanes plus a lead, each with its own branch, worktree and sdme container. Scope was locked at fourteen items and every lane was told that anything new registers forward; that lock held until the owner lifted it near the close, and the seventeen drafts it admitted were then deferred rather than folded in, so the round shipped what it chartered.

The lanes were dismissed before the release cycle and the close was carried out from the host session against the lead's written close plan.

## Validation

- Full gate green on the merged state at `219eff91`, from an isolated gate worktree on a quiet box: 1074 tests passing, zero failure signatures, and every step after `cargo test` exercised, including the gateway workspace, the web checks and `host-build-check` with a built AppImage and a devserver smoke.
- That gate had been deferred all round and recorded as a debt rather than a pass, because the tree could not go green at baseline until the terminal-test repair landed. It is the only integrated gate this round ran, and it ran once, at the end, green.
- The animation family confirmed by the owner on real Linux, Windows and macOS hardware, all four point-cloud animations by name.
- The terminal grid measurements independently reproduced by a second party on different hardware, digit for digit including gap positions, which converts a single-box reading into a replicated one.
- Not established: the boot-overlay repair is structurally correct and merged on a green gate, but **not validated by experiment**. Eighteen runs with the repair reverted produced zero reproductions, so five green runs with it in place prove nothing about it. The rig bites, reproducing an unrelated indexer class twice, and simply does not reach this defect.
- Not measured: the WebGL present stall, macOS WKWebView for the terminal grid, and any device pixel ratio other than each harness host's.

## Retrospective

Highlights: a suite that had never run found a real defect the moment it could run, and the lane that found it recommended reporting its own acceptance line unmet rather than meeting it against five of six scenarios. Three tests that looked like three problems turned out to be one missing half of an attach contract. An unverified lead was falsified and closed as not reproduced, which is a result rather than a failure to deliver. Six of fourteen status lines were found stale by a sweep rather than by waiting for reports, and two of those belonged to lanes that had already declared complete.

Lowlights: the round produced its own instance of the pattern one of its items exists to audit. The stale read lived only as prose inside the item that found it, and would have moved to `done/` as history rather than tracked work if the omission had not been caught at the close. A regression guard introduced by this round is itself unreliable under load, which is worse than no guard because it will be believed.

Honest feedback: the multi-agent round has no clock of its own. Agents end a turn, return to an empty prompt, and stop; work stalled twice for tens of minutes with every queue empty and every process alive, once with the lead having announced the gate as its next action and ended the turn on that sentence. Idle is indistinguishable from working from the outside, which is the same lesson the playbook already records about `offline` status and queue depth, arriving one level up. Separately, `cs terminal team new` reported eight agents poked and not one identity poke reached its target; the readiness gate fires before the agent CLI can accept input, and the ack proves only that bytes were written.
