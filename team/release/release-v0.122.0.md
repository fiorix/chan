# Release v0.122.0

Shipped 2026-11-02 from `0.122.0-ga`: a no-rc release of the documents sweep and one fix, cut by the merger on the Linux host on the owner's word ("proceed to the next release, no rc, ga and tag"). The sweep was rebased onto `main` by a subagent of the merger; the fix was built by the owner's macOS seat; the merger reviewed both, added one fix of its own, and gated `v0122/int` on the Linux host until the owner moved the gate to GitHub's runs.

## What shipped

- `launcherkeys`, the Computers launcher takes no keys after an app switch: on macOS, with the launcher over a window whose terminal runs on the ghostty engine, a switch to another application and back left the launcher deaf until clicked. The Mac seat's scripted readings placed it: the launcher lost the keyboard only on ghostty and only after the window was occluded, because the host page's resume refocus (the ghostty blur-then-focus wake fix) is a real focus change that WebKit answers by making the host's webview first responder. chan-desktop now marks the host page's root with `data-launcher-shown` while its launcher shows, and the terminal skips its resume refocus while the mark is set; two mounted tests were red on the base (`dd96e1265`, landed as `ffd923265`). The merger's review found that only the hide cleared the mark, so a launcher dropped while its host is hidden in place, or a show that gave the launcher no keyboard, left a window's terminal without its resume refocus until the next toggle; the merger's commit clears it on both, pinned by a test red on the seat's code (`a95c26ef7`). The owner accepted the seat's scripted readings in place of his own; macOS was not read after the merger's commit.
- The documents sweep: chan described as a supercharged terminal emulator in layers (a terminal emulator; scriptable from `cs`, the keyboard and the mouse; its own multiplexer plus tmux control mode; the same locally and remotely; devservers over a TCP tunnel or through a self-hosted gateway) in the root design, the README, the package descriptions and the site's copy; every crate, desktop, web and gateway design rewritten for human readers and corrected against the code; the configuration reference rebuilt from the code; the guides, the agent playbook, guides and skills refreshed; stale code comments fixed. Eleven commits by another session on the v0.121.0 base, rebased onto `main` (`2ace70b2b` to `f546ab6d5`), plus `d4ebabe94`, which points the collaboration page at the participant model's new home.
- The site redesign around terminals and remote access (`3b8298306`) reached `main` after the v0.121.0 tag, deployed by Pages then, and ships in this tree; its check is in v0.121.0's record.

Withdrawn: `seethru`, terminal bodies turn see-through after an app switch, by the owner on 2026-11-02 ("i dont think seethru even exists; we can remove it from the roadmap"): the bug he had seen was the launcher's keyboard.

## Retrospective

Highlights: one subagent rebased 118 files of documents onto a site redesign in about 14 minutes with every check rerun; the Mac seat placed a macOS focus bug by scripted readings alone; the pin patch and its Nix hashes were built while the integration gate ran. Lowlights: the seat's fix covered the show and the hide but not the third way a launcher ends, found only by reading every caller of the launcher's close; the sweep's root design rewrite removed a heading the redesign's new page linked to, and no standard check reads links from HTML into Markdown headings; the second local gate stopped during a disk stall of the host, on code unchanged from the green first gate. Honest feedback: the launcher fix shipped on scripted readings and the merger's addition on none on macOS.
