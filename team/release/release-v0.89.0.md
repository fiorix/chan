# Release v0.89.0

GA 2026-08-12. Fifteen roadmap items closed and four carried, worked by six file-disjoint lanes and a lead, across a round that had to be restarted with a new team partway through: the first team's agents were killed by an infrastructure failure, and a second lead picked the work up from the predecessor's task files and journals with no work lost. The release's defining result is that a test filed as merely load-sensitive was proven, by a discriminating experiment on a checked-in 1-CPU rig, to fail for a reason nobody had assumed. Not the 250ms retry race the draft was written against, but a process-global injection slot four tests clobber, where the obvious repair would have fixed the race, left the live mechanism in place, and turned the tests green.

## What shipped

- **The slide deck's two chords are rebindable, and assigning a held chord offers a swap instead of a dead end.** The deck's present and preview chords were in none of the shortcut registry's 32 entries, so a user rebind worked everywhere except on a deck, which is the one surface the chords are for. Both actions are registry commands now, and the capture handler was deliberately not widened to match by resolved chord: it stays gated on `builtInChordSuperseded`, because matching by resolved chord would let a rebind silently take a CodeMirror chord on every deck with nothing in the app able to name it. Beside it, the assign dialog gained a swap gesture, so `Cmd+Enter` presents and `Mod+Shift+Enter` previews from shipped defaults through the user's own config rather than by changing a default under everyone with the muscle memory. **Two acceptance cells are honestly not discharged and are host-only**: pressing the old chord on a real deck and observing nothing, and the pair's end-to-end line, are unit-pinned but not exercised against a running client. The end-to-end line is now reachable rather than met.
- **The graph node palette is configurable across three surfaces.** A dead legend implied it always had been. The per-kind hues now persist in `preferences.toml`, apply live in the SPA, and read and write through `chan config` keys, following the pattern the rest of the appearance settings already use end to end. Light and dark are settable separately because that is the part no automation can resolve, and the contact and mention tokens move together onto one settable hue. The palette is not graph-private, so the override rides the graph subtree rather than the document root, and a stored invalid hue is dropped from the outgoing write rather than poisoning it.
- **Settings is organised by concern, not by the app being configured.** The overlay was structured around which application a control belonged to; it is now derived from the command registry, which has grouped by surface for longer than Settings has existed. The mass of the work sat in the per-workspace half rather than in the extracted field primitives, and the reorganisation landed on top of the owner's live `feat/linux-terminal-grid` branch rather than beside it, per the ruling that sequenced the two. The `chan config` reader now materialises the skip-serialized graph-colour and terminal-colour subtrees from the same schema the write path uses, so a config that never set them reads its serde default instead of erroring.
- **Off macOS, `Ctrl+Shift+W` closes the tab, not the window.** The chord discarded the whole window where macOS closes the tab, and six layers could claim it. The control-terminal arm now routes through the same `app.tab.close` path every other window kind takes, which delivers the close-confirmation dialog on a live terminal, closes the window when its last tab closes, and leaves web's empty pane untouched, all by removing a special case rather than adding one. macOS `Cmd+W` on a control terminal knowingly changes: it gains the prompt every other terminal already raises. Window close moves to `Ctrl+Alt+W`, so the chord never means two things depending on which surface has focus, and an AltGr keydown (delivered on Windows with both Ctrl and Alt set) now falls through the key bridge so US-International character entry is no longer swallowed.
- **Ghostty is the terminal backend the Linux desktop defaults to.** Folded in from the owner's live branch, along with both halves of the Linux accelerated path getting a knob, the dma-buf override following the driver rather than the packaging, and a ghostty terminal opening blank on a freed screen.
- **Agy is a first-class submit agent.** Google Antigravity's `agy` CLI, the successor to gemini, joins Claude Code, Codex, Gemini, Kimi Code, and OpenCode as a named terminal submit agent. A member launched as `agy` derives to `agy` with no `CHAN_AGENT` override, `cs terminal list` reports the identity, `cs terminal write --submit=agy` is accepted, and generated team bootstrap uses its chord. Its built-in encoding is bracketed paste plus CR, chosen as the only probed shape whose one-message guarantee does not depend on the CLI's burst-coalescing timing. It was live-probed against a signed-in account on 2026-08-12; gemini stays supported and is marked for a later deprecation whose timing is undecided.
- **The path sandbox fails closed, and its four inconsistent answers become one.** A canonicalize failure on the containment checks was answered four different ways with no test holding any of them. An uncanonicalizable parent or root is now refused, missing create targets still resolve against their deepest canonical existing ancestor, and the symlink-blind lexical fallback that existed twice is consolidated behind one method whose root comes from the walker, so there is no longer a pair of same-typed path arguments to transpose. **The repair landed in two commits, and the split is the finding**: the server half stayed open after the headline repair read as complete, found by reading the acceptance against the tree rather than by reading the lane's report, which was accurate about what it had done.
- **A failed reset no longer wedges the workspace behind a retryable error.** Six of a reset's exits left the workspace cell empty with the process holding no route-layer installer to refill it, so the next access presented a permanent state as a retryable 503 forever, indistinguishable from ordinary contention. The cell is now restored on every fallible arm, the shape the sibling import path already used. **The concurrency test was deliberately dropped**: the injection seam sits downstream of the interleaving the test would need to control, so staging it needs a sleep-staged race, which is the exact class this same round is paying to remove. The repaired behaviour is covered deterministically by constructing the post-gate state directly.
- **The chan home no longer collapses to the working directory when `home_dir()` returns None.** An absent home resolved to the current directory, and the test that named the hazard could not detect it. An absent home now resolves to a named absolute path through a test seam, and a related defect where an isolated library sent its metadata to the ambient home is fixed alongside it by binding the library sidecars to config.
- **The metadata import holds the workspace cell guard across the whole operation.** The import dropped the write guard while it took the cell, leaving the slot empty and the lock free for the whole drain, extraction, rescan, and reopen. Every concurrent read saw that window as a permanent-looking 500 with no `Retry-After`, for a state that clears in seconds. The import now holds the guard end to end, the same shape the reset path has run since the failed-reset repair, so concurrent readers see a 503 with `Retry-After` and the 500 is again reachable only by a genuinely permanent double-reopen failure.
- **Killed PTY children are reaped, on portable-pty 0.9.0.** A killed terminal child is reaped rather than left as a zombie, with the Nix vendor hash refreshed for the upgrade. This carries the `#[cfg(windows)]` ConPTY child-reaping tests that no other CI arm can execute.
- **Two watch-registration health assertions no longer race the retry they injected.** Both `Degraded` assertions in the filtered-registration module, and the process-global injection slot they shared with the rest of the module, are repaired. The slot is now a path-keyed map, so parallel tests can no longer disarm one another, and the two ignored-subtree tests remove and inspect their own counter before accepting `Healthy`, making the registration claim positive rather than vacuous.
- **The empty-pane animation family is complete on Linux.** Polar Drift was the last animation still painting through a 2D canvas path and now paints through WebGL2 like the rest of the family, reproducing the alpha-fade trail with a frame that allocates nothing; the v0.88.0 note that moved the family had described the point cloud as the last 2D path and missed this one. Turbulent Oculus has a pupil again rather than a hole: its centre mask shipped at twice the source sketch's radius, and it is now a fifth of what it was.
- **The Linux CLI release artifacts are labelled musl, and they contain musl.** Two sites named the wrong libc, which is more than cosmetic: a name that says gnu on a musl binary sends an operator after the wrong runtime.

## Team and process

One round, six file-disjoint lanes plus a lead, each with its own branch, worktree and sdme container: Paths, Server, Gate, Tooling, Spa, and Chords. It was worked by a second team. The first team's agents were killed mid-round, and no work was lost, because the round's state lived in the coordination tree the way this project's rounds are structured to: every task both ways, each member's running journal, and a post-incident brief. A second lead read the predecessor's task files and journal for each handle and continued the work rather than restarting it.

What killed the first team is now a standing rule rather than an anecdote. The outgoing lead created the integration gate's worktree under `/tmp`, which on this host is a RAM-backed tmpfs, and ran a full release build through a bind mount into it. The build went into RAM, tmpfs hit 100%, and the devserver died and took every member's PTY with it. The container's 44G disk cap was irrelevant because the bytes never touched the container's own volume: a disk cap bounds the container's own volume, never a bind mount. Both rules, that and never putting a build tree under `/tmp` on this host, are recorded in the round brief and carried into the playbook.

Four owner rulings were surveyed, answered, and recorded in the roadmap items themselves rather than only in the coordination tree: reopen all three kept indexer timeout sites evidence-led, land the path-keyed watch slot rather than a cfg-gated per-handle parameter, rebase the Settings lane onto the owner's live branch, and promote the swap-path draft into scope because the deck-chord item made the owner's own request expressible and then left it refused.

Three process items ran that are not user-facing. The 1-CPU reproduction rig every timing item had been rebuilding got a checked-in form, so the next timing item pays the warm cost rather than the 9-to-19-minute cold rebuild, and a second operator who had never built it reproduced the recorded after-rate cold. The indexer timing-site classification reopened all three kept sleeps and their enclosing budgets, examined them, and kept them, a conforming outcome recorded as such rather than as a failure to change anything; that half of the commit is comments only, verified mechanically. The sdme build drivers were capped and stopped mounting the live worktree, merged from three drafts into one lane, and the storage half widened by ruling into a standing rule that every sdme container this repository creates uses the btrfs backend.

## The Windows CI story

The `ci-windows` arm ran the Rust test suite for the first time this round, and widening it to the whole workspace surfaced a large backlog of Unix assumptions in crates that had never run their tests on Windows: verbatim-versus-normalized path identity, POSIX shell harnesses, and real-PTY tests that drive a shell to completion and hang on pwsh's startup DSR query. None is a Windows product defect; the suites are platform-neutral logic whose harnesses assume a Unix host. A checkout normalization landed first (`* text=auto eol=lf`, keeping the signing script CRLF), which fixed the source-pin tests that compared `include_str!` output against `\n` in one file.

After a documented investigation, the arm was scoped to chan-library and chan-desktop, the two crates whose Windows behavior is worth testing: chan-library carries the ConPTY child-reaping tests no other arm can execute, and chan-desktop is the Windows shell. The investigation found that 17 systemd, launchd, and sdme tests had been passing vacuously on the Windows runner, asserting only the text of unit files, and that the standalone CLI, `crates/chan`, publishes no Windows binary of the kind those suites assume. The deferred full-suite port is recorded in a held draft so the narrowing is not silently permanent.

The widened run also surfaced a candidate product bug, deferred to the next version because it cannot be confirmed without a real-Windows repro. A Windows terminal picks pwsh by default, and pwsh under ConPTY emits a DSR cursor-position query at startup and blocks until something answers with a CPR. In production the SPA's terminal emulator answers, so pwsh proceeds; the open question is whether any production path runs a Windows shell before a frontend attaches to answer, or a reattach path where the CPR is suppressed, in which case that shell would deadlock at startup until a frontend attaches. Narrow and pre-existing, and held as a draft rather than claimed.

## The close review

A fable/ultracode correctness and docs review ran at the close, over the round's surface, and it caught three real defects the round itself had introduced, before the tag:

- **The chord swap shipped a fresh persisted collision.** The swap took the first holder of the captured chord and reassigned it unconditionally, so accepting it on the shipped `Mod+F` pair (two holders on every native slot) settled one holder and shipped a fresh collision with the other, the exact state the conflict dialog exists to prevent; against a registry-only holder it displayed the holder as moved while its old chord kept firing. The offer now requires exactly one holder that dispatches through the override layer.
- **The metadata-import window presented a permanent-looking 500** for a state that clears in seconds, fixed by holding the cell guard across the whole import, described above.
- **The graph-palette commit path poisoned every subsequent write.** It spread the raw stored wire palette into every `graph_colors` PATCH, and because `preferences.toml` is hand-editable and the server rejects the whole object on one bad hex, a single invalid stored hue failed every later palette write silently while the optimistic buffer kept showing the change as applied. The composite now passes through the same per-key sanitizer the paint path uses.

Four smaller findings landed with them: the number-field clamp callback now fires when an out-of-range entry lands on a bound, the `chan config` reader materialises skip-serialized subtrees, the AltGr key falls through the bridge, and `Ctrl+Alt+W` routes to a real close on the connecting screen. A docs sweep then aligned the round's correction narratives: eleven v0.89.0 items and one done item now state their verified facts in present tense with the draft comparisons dropped, and three project documents were corrected, including a config-reference row that overclaimed a Settings surface and a `ci-windows` comment that misdescribed what chan publishes.

## Validation

- All nine CI arms green at the release commit: `ci-linux`, `ci-macos`, Nix, COPR and PPA, both AUR arms, the chan container, and deb plus rpm, with `ci-windows` green under its narrowed scope after being the one red arm through the widening.
- The watch repair measured on the checked-in 1-CPU rig, cap verified from the host at `100000 100000` with `nr_throttled` recorded so the cap was biting rather than merely configured: a canonical parallel baseline of 14/20 and 19/20 red on the two assertions, 0/20 after, on the same instrument. The discriminating experiment (one injecting test per libtest process taking both to 0/20) established the shared-slot clobber as the active mechanism, and the vacuous direction was closed by mutation, each mutation run as an exact test that named the value comparison that failed rather than an exit code.
- The rig's own second-operator replay passed: an operator who had never built it reproduced 0 red / 20 runs exactly from the checked-in form alone, deriving the pre-repair revision from the repair sha with Git. It found one real gap, that the wrapper reports one aggregate result per test process and cannot, as checked in, reproduce the per-test rates in which this round's most-cited result was recorded, and that gap is stated in the item rather than left to be rediscovered.
- The failed-reset wedge was reproduced in-process against the unrepaired control flow before any production code changed, both config-lock exits exercised, with a first red run discarded because it failed for the wrong reason.
- **Not validated by experiment**: the WebGL present stall was measured on the first host that qualified (Arch Linux, AMD HawkPoint, Xorg, WebKitGTK 2.52.5), and it does not reproduce, but the item does not close. No arm that painted showed a stall, and the shipped `WEBKIT_DISABLE_DMABUF_RENDERER=1` configuration cannot composite the WebGL layer at all: it reports the renderer loaded and then puts zero ink on screen in 36 of 36 trials where the DOM renderer paints 12 of 12, confirmed on two independent capture paths. That is worse than the stall it was suspected of, and it means the exit-0 branch that would have licensed turning WebGL on is dead as written.
- **Not established**: the intermittent stale read carried from v0.88.0, still deferred on a recorded precondition. Host-only acceptance cells were collected rather than surveyed per cell, including the Settings theme combinations, `make aur-check`, `make windows-cross-check`, and the nix-sdme-check peak-memory measurement.

## Retrospective

Highlights: a test filed as load-sensitive was not repaired against the cause it was filed with. The discriminating experiment ran, was decisive, and showed that the naive repair would have fixed the assumed retry race, left the live shared-slot mechanism in place, and turned the tests green, which is the failure mode the round exists to avoid. The 1-CPU rig every timing item had rebuilt from scratch got a checked-in form and a cold second-operator reproduction. The close review caught three defects the round had introduced before they shipped, and one of those, the canonicalize repair, had already been caught by reading the acceptance against the tree, which found the server half open after the lane had honestly reported the item done. A malformed but green artifact was recorded rather than hidden: a test file used a literal NUL delimiter that made git classify it as binary, so four new tests produced no diff and could not be blamed, green and correct throughout, and invisible to every tool around the gate.

Lowlights: the round produced defects the review had to catch, and two of the three, the chord-swap collision and the import 500, were introduced by this round's own items and would have shipped without the review. The Windows arm's first real run surfaced a backlog large enough that the honest resolution was to narrow scope to two crates rather than port everything, leaving the full Windows suite deferred and 17 vacuously passing tests removed rather than made meaningful. The Linux terminal grid residual still stands, and the measurement that was meant to license a fix instead established that the fix is unavailable in the shipped artifact, so the residual now carries a measurement behind it rather than a comment, which is better, but the grid is still banded.

Honest feedback: the round died once, and the cause was a container disk cap that bounded the wrong volume while a bind-mounted build tree filled a RAM-backed `/tmp` and presented as an unrelated out-of-memory kill. The recovery is the argument for how this project structures its coordination tree: a second lead reconstructed the entire round state from task files and journals with no work lost, which only worked because the outgoing lead had written down what was verified separately from what was assumed. The rig work also surfaced, a third independent time, that this project's timing audits can only see sites carrying a lexical `sleep`, so a wait with no lexical signature stays invisible to the population the audit enumerates.

## Follow-ups

- The intermittent stale read carries into the next version again, still deferred on its recorded precondition, an external write to a file open with unsaved edits leaving the API serving old content and the editor never converging.
- The WebGL present stall is reframed rather than closed. The question is no longer whether the stall reproduces but why the WebGL layer never composites under `WEBKIT_DISABLE_DMABUF_RENDERER=1`, and whether the AppImage can stop needing that switch, which is a workaround for a dma-buf EGL abort on GPUs the tree does not identify. Three paths are named in the item in rising cost, and the comment inside the renderer decision is now wrong as written and should say what the measurement says.
- The frame-rate acceptance guard carried from v0.88.0 produced three findings about how to write a frame-rate acceptance line, each of which outlived the ask that produced it: a renderer string cannot prove hardware acceleration, the engine the Linux desktop ships misreports what it is rasterizing on, and a dead animation reads as the fastest arm. No code shipped for it.
- AUR restoration stays blocked upstream, re-checked and found unmet on 2026-08-10.
- Two Windows drafts are held for the owner: the full Rust suite port deferred by the scope narrowing, and the candidate ConPTY startup-DSR product bug, which needs a real-Windows repro before it is scope.
- The citation rule and its checker were withdrawn by owner ruling near the close: the item moved to `done/` stating plainly it did not ship, and `scripts/citation-check.py` was removed. The citation records added to live items while the rule was in force stay accurate but are no longer verified by anything, which was flagged to the owner rather than churned across the files.
- Several drafts sit unaccepted in the gitignored drafts tree, including the error-suppression class as unaudited, the untested wipe-dir retry budget that points at the failed-reset item's severe half, and the editor chords missing from the shortcut registry.
